اكتب مقالك.
واختار تصنيفه.

لوحة التحرير مجانية على Pages CMS، وبتحفظ المقالات والصور في مستودع GitHub. دي بوابة إرشادات، مش صفحة تسجيل دخول محلية.

افتح Pages CMS ↗

أول مرة بس

  1. ادخل بحساب GitHub صاحب الموقع.
  2. وقت تثبيت GitHub App اختار Only select repositories، وحدد eslamtgd-test بس. راجع الصلاحيات قبل الموافقة.
  3. افتح مستودع eslamtgd-test وفرع main. ملف .pages.yml جاهز في الحزمة.

عشان تنشر مقال

  1. افتح «المقالات بكل التصنيفات»، واضغط إنشاء مقال.
  2. اكتب العنوان والوصف، اختار التاريخ والتصنيف، واكتب المحتوى. فعّل «مقال مهم» لو عايزه في شريط الأهم. تقدر ترفع صورة غلاف وصور داخل المقال.
  3. سيب مفتاح النشر مقفول لو لسه بتكتب. افتحه لما تخلص واضغط حفظ. استخدم تاريخ النهارده أو تاريخ سابق.
  4. استنى بناء GitHub Pages. غالبًا التحديث يظهر خلال دقائق، وقد يصل إلى 10 دقائق. المقال هيظهر تلقائيًا في قسمه وفي أحدث المقالات.
المستودع مجاني وعلني: المسودة مش هتظهر في صفحات الموقع، لكن نصها وصورها ممكن يتشافوا في ملفات GitHub وتاريخ التعديلات. ما تحفظش بيانات خاصة أو أسرار هنا.

قبل ما تبدأ

لازم ترفع ملفات v8 مع المجلدات والملفات اللي بتبدأ بنقطة، وتحذف ملف .nojekyll القديم من مستودع التجربة. ما ترفعش الحزمة على المستودع الأساسي. إعداد رفع الصور مربوط حاليًا بمسار eslamtgd-test؛ النقل لمكان تاني محتاج تعديل بسيط.

حقول المقال بالعربي. أزرار واجهة الخدمة نفسها ممكن تظهر بالإنجليزي. الحفظ وتسجيل الدخول محتاجين تفعيلك للخدمة، ومش متجربين بحسابك لسه. مفيش جدولة تلقائية أو تعليقات في الحزمة.
