نسخة اختبار مستقلة، ليست للموقع الأساسي

ابدأ بالخطوة 1 فقط، وابعت صورة بعدها.

1) افتح GitHub، اضغط + ثم New repository. سمّه eslamtgd-test واختار Public، وبعدها Create repository. ابعت صورة.
2) في المستودع الجديد اضغط uploading an existing file أو Add file ثم Upload files. فك ضغط الحزمة على الكمبيوتر وارفع محتويات المجلد نفسه، مش ملف ZIP ومش المجلد الخارجي. لازم index.html يظهر في الجذر بجانب assets وملفات CSS وJS. اضغط Commit changes وابعت صورة.
3) افتح Settings ثم Pages. عند Source اختار Deploy from a branch، وعند Branch اختار main ثم /(root)، واضغط Save. ابعت صورة.
4) انتظر لحد ما GitHub يظهر رابط الموقع، وافتح الرابط الموجود عنده. ابعت الرابط وصورة الصفحة عشان نراجعها سوا. لا تضف eslamtgd.top في Custom domain.

المستودع Public يعني الملفات والمحتوى المرفوعين متاحين للناس، لكن مفيش أسرار أو إعلانات فعلية في الحزمة. لا ترفع بيانات دخول أو ملفات خاصة.
النسخة دي تشتغل بروابط نسبية تحت مسار مستودع GitHub Pages. مفيهاش CNAME أو معرف ناشر إعلاني. ملف robots ووسم noindex لتقليل الفهرسة، مش وسيلة لحماية محتوى خاص.
